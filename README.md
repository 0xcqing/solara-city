Solara City is an original open-world crime sandbox. Experience the thrill of exploring a city on foot or by car, complete with traffic, pedestrians, and car theft mechanics. Test your skills against a reactive police force with a wanted system.

Features:
- Story missions
- HUD with minimap and wanted stars
- Game saves

Technical Details:
- The game uses static files located in the game/ directory, with no build step required.
- To run, use `node serve.ts` and open game/index.html in your browser.
- To run the entry program, use: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
